# Sprint 3 - BigQuery

Data Analytics project developed as part of the IT Academy program.

## Project Overview

This project focuses on working with Google BigQuery and implementing a Bronze-Silver-Gold data architecture.

### Main topics

- BigQuery datasets and cloud architecture
- External and native tables
- Data ingestion from CSV files
- Query cost analysis and optimization
- Data cleaning and transformation (ELT)
- SAFE_CAST and data type conversion
- UNION ALL and JOIN operations
- Arrays and UNNEST
- Views and business KPIs
- Product sales analysis
- Exporting results

## Architecture

- **Bronze:** Raw data ingestion
- **Silver:** Cleaned and transformed data
- **Gold:** Business-ready data and reporting

## Files

- SQL script containing the complete implementation
- PDF report containing the exercises, queries and execution evidence

## Technologies

Google Cloud Platform · BigQuery · SQL
